# CesiumForFluid 技术文档

## 概述

CesiumForFluid 是一个基于 Cesium 的 GPU 流体模拟系统，实现了二维浅水方程的实时模拟和渲染。

## 目录结构

```
src/MapSenior/CesiumForFluid/
├── index.vue              # Vue 3 组件：UI、Cesium 视图设置、用户交互
└── js/
    ├── FluidRenderer.js   # 核心编排器：纹理、相机、渲染管线、水源逻辑
    ├── CustomPrimitive.js # Cesium 图元包装器
    ├── RenderUtil.js      # 静态工具：纹理/帧缓冲/几何体创建
    └── shaders.js         # GLSL 着色器源码（5个导出）
```

## 核心技术

### 1. 模拟方法：管道模型浅水方程

基于 GPU 的二维浅水模拟，使用"管道模型"（虚拟管道法）计算流体流动。模拟在 1024×1024 网格上运行，每个纹素代表一个模拟单元。

**核心原理：**
- 每个单元存储地形高度和水深
- 根据静水压力差（地形+水位高度）计算相邻单元间的流量
- 流量存储为 4 分量向量（右、上、左、下）
- 通过流入流出平衡更新水位

### 2. 多通道乒乓缓冲管线

使用 4 个 RGBA FLOAT 纹理（A、B、C、D）双缓冲，每帧 4 个计算通道：

| 通道 | 着色器 | 读取 | 写入 | 用途 |
|------|--------|------|------|------|
| 1 | BufferA | C(高度), D(流量) | 纹理 A | 更新水位（第1次）：地形查询、水源注入、流量平衡 |
| 2 | BufferB | A(高度), D(流量) | 纹理 B | 更新流量（第1次）：基于高度差计算新流量 |
| 3 | BufferC | A(高度), B(流量) | 纹理 C | 更新水位（第2次）：使用更新后的流量 |
| 4 | BufferD | C(高度), B(流量) | 纹理 D | 更新流量（第2次）：使用更新后的高度 |

双通道设计提高了稳定性和收敛速度。

### 3. 数据编码

**高度纹理（A、C）：**
- `.r` = 归一化地形高程
- `.g` = 水深（归一化）

**流量纹理（B、D）：**
- `.r` = 向右流量 (+x)
- `.g` = 向上流量 (+y)
- `.b` = 向左流量 (-x)
- `.a` = 向下流量 (-y)

### 4. 流体参数（fluidParam vec4）

- `.x` (默认 0.995)：前一帧流量的阻尼系数，控制动量/粘度
- `.y` (默认 0.25)：新压力驱动流量的缩放因子
- `.z` (默认 0.0001)：最小总流量阈值，低于此值流量归零以防止数值噪声
- `.w` (默认 0.1)：当前未使用

**守恒约束：** 如果总流出量超过可用水深，流量按比例缩减。

### 5. 高度图生成

`FluidRenderer._generateHeightMapTexture()` 通过以下步骤捕获地形高程：

1. 创建正交相机俯视模拟区域（ENU 坐标系，负 Z 方向）
2. 劫持 Cesium 内部深度预通道渲染命令（`frustumCommandsList` 索引 2）
3. 通过 `_modifyFragmentShader()` 修补片段着色器，输出局部空间 Z 高度到红色通道
4. 在 1024×1024 离屏 FBO 中渲染
5. 复制结果到持久 FLOAT 纹理

着色器补丁使用 `u_inverseEnuMatrix` 将顶点从模型坐标转换到 ENU 局部坐标，然后写入 `posMC.z`（局部高程）到 `out_FragColor.r`。

### 6. 最终渲染（renderShaderSource）

水体作为体积效果在单位立方体图元内渲染。

**顶点着色器：**
- `vo`：模型坐标系中的相机位置
- `vd`：射线方向（位置 - 相机原点）

**片段着色器光线追踪：**

1. 射线-盒子相交计算入口/出口点
2. 对地形表面进行光线步进（最多 80 步，步长 = 高度差 × 0.1）
3. 对水面（地形 + 水深）进行光线步进
4. 如果先击中水面：
   - 使用 4 级渐变计算水深颜色（蓝→黄→橙→红），由 `waterDepthColorIntensity` 控制
   - 基于水体厚度的雾效混合地形色和水色（`customParam.x` 控制雾密度）
   - Phong 反射高光（`customParam.y` = 光泽度，`customParam.z` = 镜面强度）
5. 水面法线通过高度场中心差分计算
6. 未击中水体则丢弃片段（透明）

地形颜色来自 `colorTexture`（Cesium 的 globe 颜色帧缓冲），因此实际地球影像可透过水体显示。

### 7. 大气后处理（atmosphereFs）

全屏后处理阶段实现单次散射大气渲染：
- Rayleigh 散射（`betaR`）和 Mie 散射（`betaM`），标准地球大气参数
- 地球半径 6360 km，大气半径 6420 km
- 16 个主射线采样，每个主采样 4 个光线采样
- 使用 `czm_sunPositionWC` 作为太阳方向
- 色调映射：`1 - exp(-2.2 * color)`

### 8. 边界系统

用户可在地形上绘制多边形边界：

1. 收集屏幕空间点击，通过 ENU 逆变换转换为 UV 坐标
2. 使用射线投射点在多边形内测试将多边形光栅化为 1024×1024 FLOAT 掩码纹理
3. BufferA/B/D 着色器采样掩码，边界外单元水体逐帧消散（每帧 × 0.95），流向掩码外邻居的流量被阻断

### 9. 水源系统

两种水注入模式：

**点击模式：**
- 设置 `waterSourcePos` UV 约 100ms
- 注入量：`waterSourceStrength × clickVolumeToNormalized × falloff²`
- falloff 为 `waterSourceRadius` 内的径向距离

**连续模式：**
- 设置 `continuousSourcePos` UV
- 每帧注入：`flowRate × deltaTime × flowToNormalized × falloff²`

单位系统（`_calculateUnitSystem`）在物理单位（立方米）和归一化纹理空间值之间转换，考虑像素面积和高度缩放。

## Cesium API 使用

### 核心 API

- `Cesium.ComputeCommand` - GPU 计算通道（模拟缓冲区）
- `Cesium.DrawCommand` - 最终水体渲染通道
- `Cesium.ShaderProgram.fromCache` / `Cesium.ShaderSource` - 着色器编译
- `Cesium.Texture`, `Cesium.Framebuffer`, `Cesium.Renderbuffer` - GPU 资源管理
- `Cesium.VertexArray.fromGeometry` - 几何体上传
- `Cesium.Camera` + `OrthographicOffCenterFrustum` - 高度图捕获
- `Cesium.Transforms.eastNorthUpToFixedFrame` - 坐标系变换
- `Cesium.PostProcessStage` - 大气效果
- `scene.postRender` 事件 - 帧计时

### 内部 API（私有）

- `scene._view.frustumCommandsList` / `scene._view.passState` - 访问内部渲染管线
- `context.shaderCache.getDerivedShaderProgram` / `createDerivedShaderProgram` - 着色器补丁
- `Cesium.ShaderSource.replaceMain` - 非破坏性片段着色器修改
- `context.createViewportQuadCommand` - 纹理复制工具

### 其他 API

- `Cesium.sampleTerrainMostDetailed` - 地形高程采样
- `Cesium.ScreenSpaceEventHandler` - 鼠标交互

## 关键类和方法

### FluidRenderer.js

**核心类，负责整个流体模拟和渲染的编排。**

**主要方法：**

- `constructor(viewer, options)` - 初始化渲染器，设置模拟区域
- `_initializeTextures()` - 创建 4 个 RGBA FLOAT 纹理（A/B/C/D）
- `_generateHeightMapTexture()` - 捕获地形高度到纹理
- `_createComputeCommands()` - 创建 4 个计算通道
- `_createRenderCommand()` - 创建最终水体渲染命令
- `_update(frameState)` - 每帧更新逻辑
- `addWaterSource(cartesian3, volume)` - 点击添加水源
- `startContinuousFlow(cartesian3, flowRate)` - 开始连续流
- `stopContinuousFlow()` - 停止连续流
- `setBoundary(cartesianArray)` - 设置边界多边形
- `clearBoundary()` - 清除边界

### CustomPrimitive.js

**Cesium 图元包装器，将计算和绘制命令集成到 Cesium 渲染循环。**

**主要方法：**

- `constructor(options)` - 接收计算命令数组和绘制命令
- `update(frameState)` - 执行所有计算命令，然后执行绘制命令

### RenderUtil.js

**静态工具类，提供纹理、帧缓冲、几何体创建辅助方法。**

**主要方法：**

- `createTexture(context, options)` - 创建纹理
- `createFramebuffer(context, colorTexture)` - 创建帧缓冲
- `createBoxGeometry()` - 创建单位立方体几何体

### shaders.js

**导出 5 个 GLSL 着色器源码字符串：**

- `bufferAShaderSource` - 更新水位（第1次）
- `bufferBShaderSource` - 更新流量（第1次）
- `bufferCShaderSource` - 更新水位（第2次）
- `bufferDShaderSource` - 更新流量（第2次）
- `renderShaderSource` - 最终水体渲染（光线追踪）

## 技术特点

### 优势

1. **完全 GPU 加速** - 所有计算在 GPU 上并行执行，性能高效
2. **物理真实** - 基于浅水方程，模拟结果符合流体力学
3. **实时交互** - 支持点击注水、连续流、边界绘制
4. **视觉效果丰富** - 水深渐变色、镜面高光、大气散射
5. **与 Cesium 深度集成** - 水体与真实地形、影像无缝融合

### 技术亮点

- 双通道乒乓缓冲提高数值稳定性
- 劫持 Cesium 内部渲染管线捕获地形高度
- 体积光线追踪实现水体透明效果
- 单位系统转换支持物理量输入

### 局限性

- 依赖 Cesium 私有 API，版本升级可能导致兼容性问题
- 固定 1024×1024 分辨率，大区域精度受限
- 二维模拟，无法表现三维流体效果

## 使用示例

```javascript
// 创建流体渲染器
const fluidRenderer = new FluidRenderer(viewer, {
  center: Cesium.Cartesian3.fromDegrees(116.4, 39.9, 0),
  width: 1000,  // 米
  height: 1000
});

// 点击添加水源（100 立方米）
fluidRenderer.addWaterSource(clickPosition, 100);

// 开始连续流（10 立方米/秒）
fluidRenderer.startContinuousFlow(position, 10);

// 设置边界
fluidRenderer.setBoundary([pos1, pos2, pos3, pos4]);

// 调整参数
fluidRenderer.setFluidParams({
  damping: 0.995,
  flowScale: 0.25,
  minFlow: 0.0001
});
```
