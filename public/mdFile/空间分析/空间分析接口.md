# 空间分析接口

本页覆盖 `src/FFCesium/core/libs/SpatialAnalysis/SpatialAnalysisClass.js`。

实例入口：

```js
const analysis = ffCesium.spatialAnalysisClass;
```

内部基于 `@turf/turf` 的布尔空间关系判断，返回值均为 `boolean`。

## 方法

| 方法 | 说明 |
| --- | --- |
| `judgePointAndPolygon(point, polygon)` | 判断点是否与面相交或落在面内 |
| `judgePolylineAndPolygon(polyline, polygon)` | 判断线是否与面相交 |
| `judgePolygonAndPolygon(polygon1, polygon2)` | 判断两个面是否相交 |

## 参数格式

点：

```js
[118.135, 24.339]
```

线：

```js
[
  [118.12, 24.33],
  [118.15, 24.35]
]
```

面：

```js
[
  [
    [118.12, 24.33],
    [118.15, 24.33],
    [118.15, 24.35],
    [118.12, 24.35]
  ]
]
```

## 示例

```js
const pointInPolygon = ffCesium.spatialAnalysisClass.judgePointAndPolygon(
  [118.135, 24.339],
  [[
    [118.12, 24.33],
    [118.15, 24.33],
    [118.15, 24.35],
    [118.12, 24.35]
  ]]
);

const polylineHit = ffCesium.spatialAnalysisClass.judgePolylineAndPolygon(
  [
    [118.11, 24.32],
    [118.16, 24.36]
  ],
  [[
    [118.12, 24.33],
    [118.15, 24.33],
    [118.15, 24.35],
    [118.12, 24.35]
  ]]
);
```

## 注意事项

- 传入的是二维经纬度，不是 `Cartesian3`。
- 方法内部会补闭合点，调用方无需重复写首尾点。
