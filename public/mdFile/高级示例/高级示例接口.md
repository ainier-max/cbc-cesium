# 高级示例接口

本页覆盖 `src/FFCesium/core/libs/AdvancedExamples/AddTypeClass.js`。

实例入口：

```js
const advanced = ffCesium.addTypeClass;
```

适合 Vue 组件 DOM 叠加、DOM 碰撞检测和按区域显示地图。

## 方法

| 方法 | 说明 |
| --- | --- |
| `addHtmlForVue(lngLatHeight, htmlOverlay, offset)` | 将现有 DOM 元素跟随到三维坐标 |
| `closeHtmlForVue(htmlOverlay)` | 关闭 DOM 跟随 |
| `openDivCollisionChecking(allHtmlOverlay, option)` | 开启 DOM 碰撞检测 |
| `closeDivCollisionChecking()` | 关闭 DOM 碰撞检测 |
| `showMapByAreaLngLat(LngLats)` | 仅显示指定区域，区域外裁切透明 |

## Vue DOM 叠加

### 示例

```js
const htmlOverlay = document.getElementById("station-card");
htmlOverlay.lngLatHeight = [118.135, 24.339, 20];

ffCesium.addTypeClass.addHtmlForVue(
  [118.135, 24.339, 20],
  htmlOverlay,
  { top: 10, left: 0 }
);
```

### 说明

- `htmlOverlay` 必须是已存在于页面中的 DOM 元素。
- 该方法会给元素挂载 `removeListener`，重复绑定前会自动移除旧监听。

## DOM 碰撞检测

### 示例

```js
const overlays = [dom1, dom2, dom3];
overlays.forEach((item, index) => {
  item.lngLatHeight = data[index].lngLatHeight;
});

ffCesium.addTypeClass.openDivCollisionChecking(overlays, {
  opacity: 0
});
```

### 说明

- `allHtmlOverlay` 中的每个元素都需要补充 `lngLatHeight` 字段。
- 碰撞时会根据元素对应点位与当前相机的距离，自动降低较远元素的透明度。

## 根据区域裁切地图

### 参数格式

`showMapByAreaLngLat(LngLats)` 接收扁平数组：

```js
[
  118.12, 24.33,
  118.15, 24.33,
  118.15, 24.35,
  118.12, 24.35
]
```

### 示例

```js
ffCesium.addTypeClass.showMapByAreaLngLat([
  118.12, 24.33,
  118.15, 24.33,
  118.15, 24.35,
  118.12, 24.35
]);
```

### 效果说明

- 自动开启 `depthTestAgainstTerrain`
- 关闭天空盒和大气层
- 使用 `ClippingPolygonCollection` 对区域外进行裁切
- 同时绘制一圈走廊高亮边界
