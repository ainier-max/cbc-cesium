# 地图效果接口

本页覆盖 `src/FFCesium/core/libs/MapEffect` 下的四个效果类。

## ParticleEffectClass

实例入口：

```js
const particleApi = ffCesium.particleEffectClass;
```

### 方法

| 方法 | 说明 |
| --- | --- |
| `addParticleEffect(option)` | 添加粒子系统，返回 `ParticleSystem` |
| `removeParticleEffect(primitive)` | 移除粒子系统 |

### 常用参数

该方法会在原生 `Cesium.ParticleSystem` 配置基础上，额外读取：

```js
{
  lngLatHeight: [118.135, 24.339, 0],
  headingAngle: 0,
  pickAngle: -30,
  image: "/particle/smoke.png",
  startColor: Cesium.Color.WHITE,
  endColor: Cesium.Color.WHITE.withAlpha(0),
  particleLife: 1.5,
  speed: 5,
  emissionRate: 20
}
```

## WeatherEffectClass

实例入口：

```js
const weatherApi = ffCesium.weatherEffectClass;
```

### 方法

| 方法 | 说明 |
| --- | --- |
| `addRainEffect(option)` / `removeRainEffect(stage)` | 雨效果 |
| `addSnowEffect(option)` / `removeSnowEffect(stage)` | 雪效果 |
| `addFogEffect(option)` / `removeFogEffect(stage)` | 雾效果 |
| `addCloudEffect(option)` / `removeCloudEffect()` | 云效果 |

### 参数示例

雨：

```js
{
  tiltAngle: -0.4,
  rainSize: 0.6,
  rainWidth: 20,
  rainSpeed: 120
}
```

雪：

```js
{
  snowSpeed: 80
}
```

雾：

```js
{
  alpha: 0.7
}
```

云：

```js
{
  lng: 118.135,
  lat: 24.339,
  height: 1500,
  scaleX: 600,
  scaleY: 250,
  slice: 0.36,
  color: "#FFFFFF",
  maximumSizeX: 300,
  maximumSizeY: 120,
  maximumSizeZ: 80
}
```

### 注意事项

- `removeCloudEffect()` 当前会清空整组云，不区分单个 cloud 实例。

## PolygonEffectClass

实例入口：

```js
const polygonEffect = ffCesium.polygonEffectClass;
```

### 方法

| 方法 | 说明 |
| --- | --- |
| `addWaterSurfaceEffect(lnglatArr, option)` | 添加水面效果 |
| `removeWaterSurfaceEffect(polygonPrimitive)` | 删除水面效果 |
| `addWaterVolumeEffect(lnglatArr, option)` | 添加挤出水体效果 |
| `removeWaterVolumeEffect(polygonPrimitive)` | 删除水体效果 |

### 参数示例

```js
const water = ffCesium.polygonEffectClass.addWaterSurfaceEffect(
  [
    [118.12, 24.33],
    [118.15, 24.33],
    [118.15, 24.35],
    [118.12, 24.35]
  ],
  {
    image: "/waterNormals.jpg",
    frequency: 1000,
    animationSpeed: 0.02,
    amplitude: 8
  }
);
```

`addWaterVolumeEffect` 额外读取：

```js
{
  height: 0,
  extrudedHeight: 50
}
```

## PolylineEffectClass

实例入口：

```js
const polylineEffect = ffCesium.polylineEffectClass;
```

### 方法

| 方法 | 说明 |
| --- | --- |
| `addPolylineMovePoint(movePointArr, option)` / `removePolylineMovePoint(arr)` | 在线上添加移动点 |
| `addPolylineFlicker(lnglatArr, option)` / `removePolylineFlicker(obj)` | 闪烁线 |
| `addLineSegmentLabel(lnglatHeightArr, option)` / `removeLineSegmentLabel(arr)` | 线段标签 DOM |
| `addPolylineFlow(lnglatArr, option)` / `removePolylineFlow(obj)` | 流动线 |

### 参数示例

移动点：

```js
const movePoints = ffCesium.polylineEffectClass.addPolylineMovePoint(
  [
    [118.135, 24.339],
    [118.145, 24.349],
    [118.155, 24.359]
  ],
  {
    addType: "entity", // entity | primitive
    height: 20,
    pixelSize: 8,
    color: "#F97316",
    alpha: 1
  }
);
```

闪烁线：

```js
const flicker = ffCesium.polylineEffectClass.addPolylineFlicker(
  [
    [118.135, 24.339, 0],
    [118.145, 24.349, 0]
  ],
  {
    addType: "entity",
    width: 5,
    color: "#22C55E"
  }
);
```

线段标签：

```js
const labels = ffCesium.polylineEffectClass.addLineSegmentLabel(
  [
    [118.135, 24.339, 0],
    [118.145, 24.349, 0],
    [118.155, 24.359, 0]
  ],
  {
    label: ["A 段", "B 段"],
    styleStr: "padding:4px 8px;background:#0f172a;color:#fff;border-radius:4px;",
    zIndex: 10,
    mapID: ffCesium.cesiumID,
    offset: { top: 10, left: 0 }
  }
);
```

流动线：

```js
const flow = ffCesium.polylineEffectClass.addPolylineFlow(
  [
    [118.135, 24.339, 0],
    [118.145, 24.349, 0]
  ],
  {
    width: 6,
    color: "#38BDF8",
    url: "/line-flow.png",
    time: 2000
  }
);
```

### 注意事项

- `addPolylineMovePoint` 的 `movePointArr` 应传二维经纬度数组。
- 当前版本更推荐 `addType: "entity"` 配合 `addPolylineFlicker` 使用。
