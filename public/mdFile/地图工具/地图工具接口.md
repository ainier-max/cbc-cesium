# 地图工具接口

本页覆盖坐标转换、测量、鼠标提示和几何辅助类：

- `ffCesium.mapToolClass`
- `ffCesium.mapUtilClass`
- `TransformClass`（默认未挂到 `ffCesium`，需单独引入）

## MapToolClass

实例入口：

```js
const tool = ffCesium.mapToolClass;
```

### 常用方法

| 方法 | 说明 |
| --- | --- |
| `addSkyBox(option)` / `removeSkyBox()` | 添加或恢复天空盒 |
| `cartesian3ToLngLat(cartesian3)` | 世界坐标转经纬高对象 |
| `lngLatToCartesian3({ lng, lat, height })` | 对象转 `Cartesian3` |
| `lngLatArrToCartesian3([lng, lat, height])` | 数组转 `Cartesian3` |
| `openMapInfo(option)` / `closeMapInfo()` | 打开/关闭鼠标经纬度显示 |
| `measureLineLength(callback)` / `clearMeasureLineLengthEntitys()` | 量距 |
| `measureAreaSpace(callback)` / `clearMeasureAreaSpaceEntitys()` | 测面积 |
| `openCompassTool(option)` / `closeCompassTool()` | 指北针显示控制 |
| `openScaleTool(option)` / `closeScaleTool()` | 比例尺显示控制 |
| `setOpenMouseTipOption(option)` | 设置鼠标提示气泡颜色 |
| `openMouseTip(label)` / `updateMouseTip(label)` / `closeMouseTip()` | 鼠标跟随提示 |
| `createBezierSpline(latlngArr)` | 贝塞尔平滑线 |

### 典型配置

天空盒：

```js
{
  px: "/sky/px.jpg",
  nx: "/sky/nx.jpg",
  py: "/sky/py.jpg",
  ny: "/sky/ny.jpg",
  pz: "/sky/pz.jpg",
  nz: "/sky/nz.jpg"
}
```

地图信息框、指北针、比例尺：

```js
{
  top: "20px",
  left: "20px",
  right: "auto",
  bottom: "auto"
}
```

### 示例

```js
ffCesium.mapToolClass.openMapInfo({
  left: "20px",
  bottom: "20px",
  color: "#ffffff"
});

ffCesium.mapToolClass.measureLineLength((distance) => {
  console.log("总长度(米):", distance);
});

ffCesium.mapToolClass.setOpenMouseTipOption({
  backgroundColor: "#0F172A",
  color: "#F8FAFC"
});
ffCesium.mapToolClass.openMouseTip("右击结束采集");
```

## MapUtilClass

实例入口：

```js
const util = ffCesium.mapUtilClass;
```

### 常用方法

| 方法 | 说明 |
| --- | --- |
| `getCenterPosition()` | 获取当前视口中心点经纬度 |
| `getHeightAtPoint([lng, lat], level)` | 采样地形高程 |
| `getCenterPointByPolyline(lngLatArr)` | 获取折线中点 |
| `countlength(option)` | 计算线、面、矩形、圆周长 |
| `countArea(option)` | 计算面、矩形、圆面积 |
| `rectangleCoordinateToPolygonCoordinate(east, west, south, north)` | 矩形转面坐标 |
| `getLngLatFromLngLatHeight(arr)` | 经纬高转经纬度 |
| `getLngLatArrFromLngLatHeightArr(arr)` | 经纬高数组转二维经纬度数组 |
| `getCenterPointFromLngLatArr(arr)` | 计算面中心点 |
| `cartesian3ArrToLngLatHeightArr(arr)` | 世界坐标数组转经纬高数组 |
| `lngLatHeightArrToCartesian3Arr(arr)` | 经纬高数组转世界坐标数组 |
| `positionToLngLatHeight(position)` | `Cartesian3` 转 `[lng, lat, height]` |
| `isSimpleXYZ(p1, p2)` | 判断两个世界坐标是否完全相同 |
| `coordinateArrDeduplication(arr)` | 去除连续重复坐标 |
| `setAttributeForEntity(entity, option, type)` | 为实体回填 `FF*` 业务属性 |

### `countlength` / `countArea` 参数

```js
{
  type: "polygon", // polygon | rectangle | circle | polyline
  LngLatArr: [
    [118.12, 24.33],
    [118.15, 24.33],
    [118.15, 24.35]
  ],
  LngLat: {
    east: 118.15,
    west: 118.12,
    south: 24.33,
    north: 24.35
  },
  radius: 500
}
```

## TransformClass

源码路径：

```js
import TransformClass from "@/FFCesium/core/libs/MapUtil/TransformClass.js";
```

该类默认没有挂到 `ffCesium` 实例，只暴露一个方法：

| 方法 | 说明 |
| --- | --- |
| `getLngLatArrFromLngLatHeightArr(arr)` | 将 `[[lng, lat, height], ...]` 转成 `[[lng, lat], ...]` |

### 示例

```js
const transform = new TransformClass(ffCesium.viewer);
const result = transform.getLngLatArrFromLngLatHeightArr([
  [118.135, 24.339, 10],
  [118.145, 24.349, 20]
]);
```
