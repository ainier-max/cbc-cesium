# 地图标绘接口

本页覆盖普通图形采集/编辑和军标采集/编辑。

## ElementGatherClass

实例入口：

```js
const gather = ffCesium.elementGatherClass;
```

### 方法

| 方法 | 说明 |
| --- | --- |
| `forceGatherEnd()` | 强制结束当前采集并清理临时图形 |
| `gatherHandlerDestroy()` | 销毁采集事件与鼠标提示 |
| `circleGather(callback, option)` | 圆采集，右击结束 |
| `rectangleGather(callback, option)` | 矩形采集，右击结束 |
| `billboardGather(callback, option)` | 图标点采集，单击结束 |
| `pointGather(callback, option)` | 点采集，单击结束 |
| `polylineGather(callback, option)` | 线采集，右击结束 |
| `polygonGather(callback, option)` | 面采集，右击结束 |

### 回调返回值

回调拿到的是已经加入场景的 `Entity`，并附带 `FFType`、`FFOption`、`FFCoordinates`、`FFPosition` 等字段。

### 示例

```js
ffCesium.elementGatherClass.polygonGather((polygonEntity) => {
  console.log("采集完成", polygonEntity.FFCoordinates);
}, {
  color: "#22C55E",
  alpha: 0.35
});
```

### 注意事项

- `pointGather(callback, option)` 当前实现内部使用固定点样式，传入的 `option` 不会完整生效。
- 采集过程中会占用鼠标事件；如果业务中断，调用 `forceGatherEnd()` 清理最稳妥。

## ElementEditClass

实例入口：

```js
const edit = ffCesium.elementEditClass;
```

### 方法

| 方法 | 说明 |
| --- | --- |
| `rectangleEdit(entity, callback)` / `closeRectangleEdit(entity)` | 矩形编辑 |
| `circleEdit(entity, callback)` / `closeCircleEdit(entity)` | 圆编辑 |
| `polygonEdit(entity, callback)` / `closePolygonEdit(entity)` | 面编辑 |
| `polylineEdit(entity, callback)` / `closePolylineEdit(entity)` | 线编辑 |
| `pointEdit(entity, callback)` / `closePointEdit(entity)` | 点编辑 |
| `billboardEdit(entity, callback)` / `closeBillboardEdit(entity)` | 图标编辑 |

### 使用方式

通常将 `EntityClass` 或 `ElementGatherClass` 返回的实体直接传入编辑接口：

```js
const point = ffCesium.entityClass.addPointEntity([118.135, 24.339, 0], {
  pixelSize: 12,
  color: "#EAB308",
  alpha: 1
});

ffCesium.elementEditClass.pointEdit(point, (entity) => {
  console.log("编辑后坐标", entity.FFCoordinates);
});
```

## MilitaryPlottingGatherClass

实例入口：

```js
const militaryGather = ffCesium.militaryPlottingGatherClass;
```

### 方法

| 方法 | 说明 |
| --- | --- |
| `forceMilitaryGatherEnd()` | 强制结束军标采集 |
| `endMilitaryPlottingGatherDeal()` | 清理军标采集事件与控制点 |
| `addMilitaryPlotting(cartesianPoints, option, type)` | 低层方法，直接生成军标图形 |
| `rendezvousGather(callback, option)` | 集结地采集 |
| `doubleArrowGather(callback, option)` | 双箭头采集 |
| `tailedAttackArrowGather(callback, option)` | 燕尾箭头采集 |
| `straightArrowGather(callback, option)` | 直箭头采集 |

### 回调返回值

返回 `Entity`，并补充：

| 字段 | 说明 |
| --- | --- |
| `FFType` | `FFRendezvousEntity` / `FFDoubleArrowEntity` / `FFTailedAttackArrowEntity` / `FFStraightArrowEntity` |
| `FFPlotKeyPoints` | 军标控制点数组 |
| `FFCoordinates` | 军标最终面坐标 |

### 示例

```js
ffCesium.militaryPlottingGatherClass.doubleArrowGather((entity) => {
  console.log("双箭头控制点", entity.FFPlotKeyPoints);
}, {
  color: "#DC2626",
  alpha: 0.45
});
```

## MilitaryPlottingEditClass

实例入口：

```js
const militaryEdit = ffCesium.militaryPlottingEditClass;
```

### 方法

| 方法 | 说明 |
| --- | --- |
| `endMilitaryPlottingEditDeal()` | 结束当前军标编辑 |
| `rendezvousEdit(entity, callback)` / `closeRendezvousEdit(entity)` | 集结地编辑 |
| `doubleArrowEdit(entity, callback)` / `closeDoubleArrowEdit(entity)` | 双箭头编辑 |
| `tailedAttackArrowEdit(entity, callback)` / `closeTailedAttackArrowEdit(entity)` | 燕尾箭头编辑 |
| `straightArrowEdit(entity, callback)` / `closeStraightArrowEdit(entity)` | 直箭头编辑 |
| `addRendezvousEntity(lnglatArr, option)` | 直接创建集结地实体 |
| `addDoubleArrowEntity(lnglatArr, option)` | 直接创建双箭头实体 |
| `addTailedAttackArrow(lnglatArr, option)` | 直接创建燕尾箭头实体 |
| `addStraightArrowEntity(lnglatArr, option)` | 直接创建直箭头实体 |

### 示例

```js
const arrow = ffCesium.militaryPlottingEditClass.addStraightArrowEntity(
  [
    [118.135, 24.339],
    [118.165, 24.359]
  ],
  {
    color: "#2563EB",
    alpha: 0.5
  }
);

ffCesium.militaryPlottingEditClass.straightArrowEdit(arrow, (entity) => {
  console.log("更新后控制点", entity.FFPlotKeyPoints);
});
```
