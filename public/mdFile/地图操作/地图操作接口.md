# 地图操作接口

本页覆盖 `src/FFCesium/core/libs/MapOperate` 中更偏“绘制与视角控制”的接口：

- `ffCesium.mapActionClass`
- `ffCesium.entityClass`
- `ffCesium.primitiveClass`
- `ffCesium.elementClass`

## MapActionClass

实例入口：

```js
const mapAction = ffCesium.mapActionClass;
```

### 常用方法

| 方法 | 说明 |
| --- | --- |
| `getCameraLocation()` | 获取当前相机经纬高、俯仰、朝向、滚转 |
| `getCameraEvent()` | 每 2 秒输出一次相机信息到控制台 |
| `flyTo(option, callback)` | 飞行到指定点位 |
| `flyToByBoundingSphere(lnglatArr, option)` | 根据包围球飞行到多点范围 |
| `setView(option)` | 立即设置视角 |
| `resetView(lngLatHeight, option, callback)` | 保持当前相机距离，重置到新的目标点 |

### `flyTo` / `setView` 参数

```js
{
  lng: 118.135,
  lat: 24.339,
  height: 20000,
  pitchRadiu: -50,
  time: 2,
  eyeHeight: 5000
}
```

### 示例

```js
ffCesium.mapActionClass.setView({
  lng: 118.135,
  lat: 24.339,
  height: 20000,
  pitchRadiu: -50
});

ffCesium.mapActionClass.flyTo(
  {
    lng: 118.135,
    lat: 24.339,
    height: 3000,
    pitchRadiu: -35,
    eyeHeight: 1500,
    time: 2
  },
  () => console.log("定位完成")
);
```

## EntityClass

实例入口：

```js
const entityApi = ffCesium.entityClass;
```

适合业务对象需要保留 `Entity`、支持后续采集/编辑/属性回写的场景。

### 常用方法

| 方法 | 说明 |
| --- | --- |
| `addCircleEntity(centerPoint, radius, option)` | 添加圆形实体 |
| `addPointEntity(lngLatHeight, option)` | 添加点实体 |
| `addBillboardEntity(lngLatHeight, option)` | 添加图标实体 |
| `addRectangleEntity(coordinates, option)` | 添加矩形实体 |
| `addPolygonEntity(lnglatArr, option)` | 添加面实体 |
| `addPolylineEntity(lngLatHeightArr, option)` | 添加线实体 |
| `removeFFEntity(entity)` | 删除单个实体 |
| `removeFFEntityArr(arr)` | 批量删除实体 |
| `removeFFEntityID(id)` | 通过 id 删除实体 |
| `removeFFEntityIDArr(ids)` | 批量通过 id 删除实体 |

### 常用配置

点实体：

```js
{
  pixelSize: 12,
  color: "#FFCC00",
  alpha: 1,
  outlineWidth: 1,
  outlineColor: "#000000",
  id: "point-1"
}
```

图标实体：

```js
{
  image: "/img/marker.png",
  scale: 1,
  pixelOffset: [0, -20],
  id: "billboard-1"
}
```

线面矩形圆：

```js
{
  color: "#00BFFF",
  alpha: 0.4,
  width: 4,
  clampToGround: true,
  id: "shape-1"
}
```

### 示例

```js
const point = ffCesium.entityClass.addPointEntity([118.135, 24.339, 0], {
  pixelSize: 12,
  color: "#F97316",
  alpha: 1,
  outlineWidth: 1,
  outlineColor: "#111827"
});

const polygon = ffCesium.entityClass.addPolygonEntity(
  [
    [118.12, 24.33],
    [118.15, 24.33],
    [118.15, 24.35],
    [118.12, 24.35]
  ],
  {
    color: "#22C55E",
    alpha: 0.35
  }
);
```

## PrimitiveClass

实例入口：

```js
const primitiveApi = ffCesium.primitiveClass;
```

适合大量简单图元、性能优先场景。

### 常用方法

| 方法 | 说明 |
| --- | --- |
| `addGltfPrimitive(lngLatHeight, option)` | 添加 glTF/glb 模型 |
| `addBillboardPrimitive(lngLatHeight, option)` | 添加 billboard primitive |
| `addPointPrimitive(lngLatHeight, option)` | 添加 point primitive |
| `addPolylinePrimitive(lnglatArr, option)` | 添加线 primitive |
| `addPolygonPrimitive(lnglatArr, option)` | 添加面 primitive |
| `removeFFPrimitive(primitive)` | 根据 `FFtype` 删除 primitive |

### glTF 示例

```js
const model = await ffCesium.primitiveClass.addGltfPrimitive(
  [118.135, 24.339, 0],
  {
    url: "/model/demo.glb",
    headingAngle: 0,
    pitchAngle: 0,
    rollAngle: 0,
    minimumPixelSize: 64,
    maximumScale: 200
  }
);
```

### 线面 primitive 示例

```js
const polyline = ffCesium.primitiveClass.addPolylinePrimitive(
  [
    [118.135, 24.339, 0],
    [118.145, 24.349, 0]
  ],
  {
    width: 4,
    color: "#38BDF8",
    alpha: 0.9
  }
);
```

## ElementClass

实例入口：

```js
const elementApi = ffCesium.elementClass;
```

用于 HTML 覆盖物、贴地文字和圆柱体。

### 常用方法

| 方法 | 说明 |
| --- | --- |
| `addGroundLabel(lngLatHeight, option)` | 添加贴地文本 primitive |
| `removeGroundLabel(labelObj)` | 删除贴地文本 |
| `addHtml(lngLatHeight, html, option)` | 在地图容器内添加 HTML 覆盖物 |
| `removeHtml(htmlOverlay)` | 删除 HTML 覆盖物 |
| `addCylinder(linePoints, option)` | 根据两点添加圆柱体 |

### 示例

```js
const htmlOverlay = ffCesium.elementClass.addHtml(
  [118.135, 24.339, 0],
  "<div class='marker-card'>站点 A</div>",
  {
    zIndex: 10,
    offset: { top: 12, left: 0 }
  }
);

const cylinder = ffCesium.elementClass.addCylinder(
  [118.135, 24.339, 0, 118.135, 24.339, 300],
  {
    radius: 10,
    slices: 32,
    color: "#2563EB",
    alpha: 0.45
  }
);
```
