# 初始化地球

## 基本用法

```js
import FFCesium from "@/FFCesium/core/index.js";

const ffCesium = new FFCesium("cesiumContainer", viewerOption);
```

## 构造函数

```js
new FFCesium(id, option)
```

参数说明：

- `id`：承载 Cesium 场景的 DOM 节点 `id`
- `option`：Cesium `Viewer` 配置对象，另外支持 FFCesium 扩展配置

## 常用 Viewer 配置

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `animation` | `Boolean` | 是否显示左下角动画控件 |
| `baseLayerPicker` | `Boolean` | 是否显示底图选择器 |
| `baseLayer` | `Boolean` | 是否启用默认底图层 |
| `fullscreenButton` | `Boolean` | 是否显示全屏按钮 |
| `geocoder` | `Boolean` | 是否显示地理搜索框 |
| `homeButton` | `Boolean` | 是否显示 Home 按钮 |
| `infoBox` | `Boolean` | 是否显示信息框 |
| `sceneModePicker` | `Boolean` | 是否显示 2D/3D 切换 |
| `scene3DOnly` | `Boolean` | 是否只使用 3D 场景 |
| `selectionIndicator` | `Boolean` | 是否显示选中指示器 |
| `timeline` | `Boolean` | 是否显示时间轴 |
| `navigationHelpButton` | `Boolean` | 是否显示帮助按钮 |
| `shadows` | `Boolean` | 是否启用阴影 |
| `shouldAnimate` | `Boolean` | 是否启用场景动画 |
| `viewer` | `Cesium.Viewer` | 传入已有的 Viewer 实例 |
| `customOption.cacheUrl` | `string[]` | 启用本地缓存的 URL 关键字列表 |

## 默认初始化行为

当 `option` 不传时，FFCesium 会：

- 使用内置默认参数创建 `Viewer`
- 隐藏 Cesium 默认版权信息
- 加载高德底图
- 设置默认相机视角

因此，最简写法如下：

```js
const ffCesium = new FFCesium("cesiumContainer");
```

## 推荐初始化示例

```js
const viewerOption = {
  animation: false,
  baseLayerPicker: false,
  baseLayer: false,
  fullscreenButton: false,
  geocoder: false,
  homeButton: false,
  infoBox: false,
  sceneModePicker: false,
  scene3DOnly: false,
  selectionIndicator: false,
  timeline: false,
  navigationHelpButton: false,
  shadows: true,
  shouldAnimate: true
};

const ffCesium = new FFCesium("cesiumContainer", viewerOption);
```

## 复用已有 Viewer

```js
const viewer = new Cesium.Viewer("cesiumContainer", viewerOption);
const ffCesium = new FFCesium("cesiumContainer", { viewer });
```

这种方式适合：

- 项目已经有统一的 Cesium 初始化逻辑
- 需要先注入自定义 `terrainProvider`、`imageryProvider` 或上下文配置
- 只想使用 FFCesium 的封装能力，不让它重复创建 Viewer

## 缓存模式初始化

```js
const ffCesium = new FFCesium("cesiumContainer", {
  animation: false,
  baseLayerPicker: false,
  customOption: {
    cacheUrl: [
      "/webst04.is.autonavi.com/appmaptile",
      "/terrain",
      "/cesium/Assets/"
    ]
  }
});

await ffCesium.whenReady();
```

启用缓存模式时，建议在 `whenReady()` 完成后再执行后续地图业务代码。

## 初始化完成后可直接访问

```js
ffCesium.viewer
ffCesium.Cesium
```

它们分别对应：

- 当前 Cesium `Viewer` 实例
- 当前项目依赖的 Cesium 命名空间
