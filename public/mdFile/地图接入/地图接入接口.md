# 地图接入接口

本页覆盖 `src/FFCesium/core/libs/MapAccess` 下的两个入口类：

- `ffCesium.mapServerClass`
- `ffCesium.dataServerClass`

## MapServerClass

实例入口：

```js
const mapServer = ffCesium.mapServerClass;
```

适用场景：底图、影像图、注记图、自定义瓦片服务加载。

### 常用方法

| 方法 | 说明 |
| --- | --- |
| `addGaodeLayer(url)` | 加载高德或任意 URL Template 底图 |
| `addTdtVecLayer()` | 加载天地图矢量底图 |
| `addTdtCvaLayer()` | 加载天地图矢量注记 |
| `addTdtImgLayer()` | 加载天地图影像底图 |
| `addTdtCiaLayer()` | 加载天地图影像注记 |
| `addTdtCtaLayer()` | 加载天地图道路注记 |
| `addTdtLayer(url)` | 加载任意天地图风格或兼容 URL Template 服务 |
| `addArcgisImgLayer()` | 加载 ArcGIS World Imagery |
| `addCustomLayer(url)` | 加载自定义瓦片服务 |
| `removeMapLayer(layer)` | 移除已添加的图层 |
| `hideMapLayer()` | 当前版本未实现 |

### 示例

```js
const gaodeLayer = ffCesium.mapServerClass.addGaodeLayer(
  "https://webst04.is.autonavi.com/appmaptile?style=6&x={x}&y={y}&z={z}"
);

const imgLayer = ffCesium.mapServerClass.addTdtImgLayer();
const ciaLayer = ffCesium.mapServerClass.addTdtCiaLayer();

ffCesium.mapServerClass.removeMapLayer(gaodeLayer);
```

## DataServerClass

实例入口：

```js
const dataServer = ffCesium.dataServerClass;
```

适用场景：地形、3DTiles、GeoJSON、KML、WMS。

### 常用方法

| 方法 | 说明 |
| --- | --- |
| `addObliquePhotography(url, option)` | 加载 3DTiles 倾斜摄影，返回 `Cesium3DTileset` |
| `removeObliquePhotography(tileset)` | 移除倾斜摄影 |
| `addTerrain(url)` | 加载地形服务，返回 `TerrainProvider` |
| `removeTerrain()` | 恢复为椭球地形 |
| `readGeojson(geojson)` | 解析 GeoJSON，返回 `GeoJsonDataSource.load(...)` |
| `addGeojson(dataSource, option)` | 将 GeoJSON 数据源加入场景并套用样式 |
| `readKml(kml)` | 解析 KML，返回 `KmlDataSource.load(...)` |
| `addKml(dataSource)` | 将 KML 数据源加入场景 |
| `removeDataSource(dataSource)` | 移除数据源 |
| `addWmslayer(url, layerName)` | 通过服务地址和图层名加载 WMS |
| `findWmsLayer(option)` | 通过完整 `WebMapServiceImageryProvider` 配置加载 WMS |

### GeoJSON 样式参数

`addGeojson(dataSource, option)` 当前会读取这些字段：

```js
{
  stroke: "#00BFFF",
  strokeWidth: 2,
  fill: "#00BFFF",
  fillAlpha: 0.3
}
```

### 示例

```js
const tileset = await ffCesium.dataServerClass.addObliquePhotography(
  "/3dtiles/tileset.json",
  {
    maximumScreenSpaceError: 16
  }
);

const terrain = await ffCesium.dataServerClass.addTerrain("/terrain");

const geojsonDs = await ffCesium.dataServerClass.readGeojson("/data/demo.geojson");
ffCesium.dataServerClass.addGeojson(geojsonDs, {
  stroke: "#1D4ED8",
  strokeWidth: 2,
  fill: "#60A5FA",
  fillAlpha: 0.35
});

const wmsLayer = ffCesium.dataServerClass.addWmslayer(
  "https://demo.mapserver.org/cgi-bin/wms",
  "bluemarble"
);
```

### 注意事项

- `findWmsLayer(option)` 的方法名像“查询”，实际行为是“创建并添加图层”。
- `addTerrain(url)` 依赖当前 `viewer.scene.terrainProvider`，建议在地形加载成功后再做地表采样。
