# 接入指南

## 依赖版本

当前项目使用的核心依赖如下：

```json
{
  "cesium": "1.120",
  "cesium-navigation-es6": "^3.0.9",
  "vite-plugin-cesium": "^1.2.22",
  "@turf/turf": "^6.5.0",
  "vue": "^3.4.21"
}
```

安装：

```bash
npm install
```

如果是独立新项目，至少需要安装：

```bash
npm install cesium@1.120 cesium-navigation-es6@3.0.9 @turf/turf@6.5.0 vite-plugin-cesium@1.2.22
```

## Vite 配置

在 `vite.config.js` 中启用 `vite-plugin-cesium`：

```js
import { defineConfig } from "vite";
import vue from "@vitejs/plugin-vue";
import vitePluginCesium from "vite-plugin-cesium";
import { resolve } from "path";

export default defineConfig({
  plugins: [vue(), vitePluginCesium()],
  resolve: {
    alias: {
      "@": resolve(__dirname, "./src")
    }
  }
});
```

## 引入方式

### 方式一：在当前仓库内直接引用源码

```js
import FFCesium from "@/FFCesium/core/index.js";
```

### 方式二：引用打包产物

打包命令：

```bash
npm run pack
npm run packmin
npm run packconfuse
npm run packconfusemin
```

产物目录：

```text
public/lastVersion/
```

常用产物：

- `FFCesium.js`
- `FFCesium.min.js`
- `FFCesium.confuse.js`
- `FFCesium.confuse.min.js`

示例：

```js
import FFCesium from "../../../public/lastVersion/FFCesium.confuse.min.js";
```

## 基础接入示例

```vue
<template>
  <div id="cesiumContainer"></div>
</template>

<script setup>
import { onMounted } from "vue";
import FFCesium from "@/FFCesium/core/index.js";

onMounted(() => {
  const viewerOption = {
    animation: false,
    baseLayerPicker: false,
    baseLayer: false,
    fullscreenButton: false,
    geocoder: false,
    homeButton: false,
    infoBox: false,
    sceneModePicker: false,
    scene3DOnly: false,
    selectionIndicator: false,
    timeline: false,
    navigationHelpButton: false,
    shadows: true,
    shouldAnimate: true
  };

  const ffCesium = new FFCesium("cesiumContainer", viewerOption);
  ffCesium.mapActionClass.setView({
    lng: 118.135,
    lat: 24.339,
    height: 20000,
    pitchRadiu: -50
  });
});
</script>

<style scoped>
#cesiumContainer {
  width: 100%;
  height: 100%;
  overflow: hidden;
}
</style>
```

## 使用已有 Viewer

如果你的项目已经自己创建了 Cesium `viewer`，可以把它直接交给 FFCesium：

```js
const viewer = new Cesium.Viewer("cesiumContainer", viewerOption);
const ffCesium = new FFCesium("cesiumContainer", { viewer });
```

此模式下，FFCesium 不会重复创建 `Viewer`，只负责挂载封装能力。

## 开启缓存模式

如果需要对指定资源启用本地缓存，可通过 `customOption.cacheUrl` 配置：

```js
const ffCesium = new FFCesium("cesiumContainer", {
  animation: false,
  baseLayerPicker: false,
  customOption: {
    cacheUrl: [
      "/webst04.is.autonavi.com/appmaptile",
      "/terrain",
      "/cesium/Assets/"
    ]
  }
});

await ffCesium.whenReady();
```

建议在启用缓存模式时，统一在 `await ffCesium.whenReady()` 之后再执行底图、地形和业务图层加载逻辑。

## 原生 Cesium 能力访问

接入完成后，可直接访问原生对象：

```js
ffCesium.viewer
ffCesium.Cesium
```

适用于：

- 调用 FFCesium 未封装的 Cesium 能力
- 接入已有 Cesium 插件
- 处理更底层的渲染与场景逻辑
