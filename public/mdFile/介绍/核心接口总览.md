# 核心接口总览

本文档按 `src/FFCesium/core/libs` 的模块划分整理 FFCesium 的对外接口，适合在接入完成后作为 API 速查表使用。

## 使用前提

```js
import FFCesium from "@/FFCesium/core/index.js";

const ffCesium = new FFCesium("cesiumContainer", viewerOption);
await ffCesium.whenReady();
```

启用了 `customOption.cacheUrl` 时，建议统一在 `await ffCesium.whenReady()` 之后再调用各类接口。

## 模块入口

| 分类 | 实例入口 | 对应源码目录 | 说明 |
| --- | --- | --- | --- |
| 地图接入 | `ffCesium.mapServerClass` / `ffCesium.dataServerClass` | `MapAccess` | 底图、地形、GeoJSON、KML、WMS、倾斜摄影 |
| 地图操作 | `ffCesium.mapActionClass` / `ffCesium.entityClass` / `ffCesium.primitiveClass` / `ffCesium.elementClass` | `MapOperate` | 视角控制、实体绘制、Primitive、HTML/贴地标注 |
| 地图标绘 | `ffCesium.elementGatherClass` / `ffCesium.elementEditClass` / `ffCesium.militaryPlottingGatherClass` / `ffCesium.militaryPlottingEditClass` | `MapGather` | 交互采集、编辑、军标绘制 |
| 地图效果 | `ffCesium.particleEffectClass` / `ffCesium.weatherEffectClass` / `ffCesium.polygonEffectClass` / `ffCesium.polylineEffectClass` | `MapEffect` | 粒子、天气、线面特效 |
| 地图工具 | `ffCesium.mapToolClass` / `ffCesium.mapUtilClass` | `MapOperate` / `MapUtil` | 测量、坐标转换、鼠标提示、几何工具 |
| 空间分析 | `ffCesium.spatialAnalysisClass` | `SpatialAnalysis` | 点面、线面、面面关系判断 |
| 高级示例 | `ffCesium.addTypeClass` | `AdvancedExamples` | Vue DOM 叠加、DOM 碰撞检测、按区域裁切地图 |

## 返回对象约定

`EntityClass`、`ElementGatherClass`、`ElementEditClass`、军标相关接口会在返回实体上补充一些业务字段，常见如下：

| 字段 | 含义 |
| --- | --- |
| `FFType` | FFCesium 约定的图形类型，如 `FFPointEntity`、`FFPolygonEntity` |
| `FFOption` | 创建或编辑时使用的配置对象 |
| `FFCoordinates` | 经纬高坐标 |
| `FFPosition` | Cesium 世界坐标或 `Rectangle` |
| `FFCenterPoint` / `FFRadius` | 圆形实体的中心点与半径 |
| `FFPlotKeyPoints` | 军标控制点 |
